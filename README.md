<summary><b>🔎 The engineering behind the claims</b></summary>
<br />

- Performance: Replaced a shuffle-heavy join with a broadcast join, reducing one Glue transformation from 42 minutes to about 6 minutes.
- Reliability: Combined disposable staging tables with idempotent loading for safe reprocessing.
- Auditability: Implemented PL/pgSQL SCD Type 2 versioning to preserve changes over time.
- Retrieval: Combined sparse and dense search with reranking to improve the relevance of evidence supplied to AI workflows.
The production metrics describe my TCS experience. AI systems and the public pipeline are separate project work.
